description: 현재 변경사항을 논리 단위로 나눠 커밋까지 실행
argument-hint: "[맥락 설명, 생략 가능]"
---

현재 변경사항을 논리 단위로 분리하여 커밋 메시지를 결정하고, **실제로 커밋을 실행한다.**

**1단계 – 변경사항 파악**
```
git status
git diff
git diff --staged
```

**2단계 – 논리 단위 분할**
변경사항을 논리적으로 분리 가능한 단위로 나눈다.
- 기능 추가, 버그 수정, 스타일 수정, 설정 변경은 각각 분리
- 하나의 커밋은 하나의 이유로만 변경된 내용을 포함
- 너무 잘게 쪼개지 않되, 리뷰 가능한 크기로

**3단계 – 커밋 메시지 결정 후 사용자 확인**
각 단위에 대해 아래 형식으로 메시지를 제안하고, 사용자 확인 후 커밋을 실행한다.

```
[태그] 한 줄 요약 - 상세1 상세2
```

태그: `[Feat]` / `[Fix]` / `[Refactor]` / `[Chore]` / `[Test]` / `[Docs]`

커밋 단위가 2개 이상이면 분리된 계획을 먼저 보여주고 사용자 확인을 받은 후 순서대로 실행한다. 단위가 1개이면 바로 실행한다.

**4단계 – 커밋 실행**
확정된 단위 순서대로 아래 패턴으로 실행한다.

```
git add <파일 목록>
git commit -m "[태그] 한 줄 요약 - 상세1 상세2"
```

커밋 후 `git log --oneline -5`로 결과를 확인하고 보고한다.
