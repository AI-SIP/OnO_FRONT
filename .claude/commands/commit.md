---
description: 현재 변경사항의 커밋 단위 및 메시지 제안 (커밋 실행 안 함)
argument-hint: "[맥락 설명, 생략 가능]"
---

현재 변경사항에 대해 커밋 단위와 메시지를 제안한다. **커밋을 실행하지 않는다.**

**1단계 – 변경사항 파악**
```
git status
git diff
git diff --staged
```

**2단계 – 논리 단위 분할**
변경사항을 논리적으로 분리 가능한 단위로 나눈다.
- 기능 추가, 버그 수정, 스타일 수정, 설정 변경은 각각 분리
- 하나의 커밋은 하나의 이유로만 변경된 내용을 포함
- 너무 잘게 쪼개지 않되, 리뷰 가능한 크기로

**3단계 – 커밋 메시지 작성**
각 단위에 대해 아래 형식으로 메시지를 제안한다.

```
[태그] 한 줄 요약 - 상세1 상세2
```

태그: `[Feat]` / `[Fix]` / `[Refactor]` / `[Chore]` / `[Test]` / `[Docs]`

**출력 형식**:
```
## 커밋 1
git add <파일 목록>
git commit -m "[Feat] ..."

## 커밋 2
git add <파일 목록>
git commit -m "[Fix] ..."
```
