description: 코드 흐름·원리 설명 (읽기 전용, 학습용)
argument-hint: "<파일명, 위젯명, 또는 기능 설명>"
---

$ARGUMENTS 코드의 흐름과 원리를 설명한다.

**규칙**: 이 명령은 읽기 전용이다. 코드를 수정하거나 커밋하지 않는다.

**1단계 – 진입점 파악**
`code-tracer` 에이전트와 함께 아래를 추적한다.
- 위젯 트리에서 어디서 시작하는가
- 상태 관리 흐름 (Provider/Riverpod/Bloc 등): 상태가 어디서 만들어지고 어디서 소비되는가
- API 호출 경로: 어느 위젯 → 어느 서비스/레포지토리 → 어느 엔드포인트

**2단계 – 흐름 정리**
- 실행 순서를 따라 단계별로 설명
- 각 단계의 근거를 `파일:라인`으로 인용
- 왜 이렇게 구현되어 있는지 (설계 의도, 제약, 트레이드오프)를 설명
- 처음 보는 사람도 이해할 수 있도록 Flutter 관용 패턴이 있으면 함께 설명

**3단계 – 요약**
```
## 흐름 요약
1단계: [파일:라인] 설명
2단계: ...

## 핵심 설계 이유
- ...

## 주의할 동작 / 알아두면 좋은 점
- ...
```
