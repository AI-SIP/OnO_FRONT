---
description: 변경사항 다관점 검증 및 위험도 분류 (읽기 전용)
argument-hint: "[커밋 해시, 생략 시 현재 변경사항]"
---

$ARGUMENTS 변경사항을 검증한다. 커밋 해시가 있으면 해당 커밋부터 HEAD까지, 없으면 현재 변경사항만 검토한다.

**규칙**: 이 명령은 읽기 전용이다. 코드를 수정하거나 커밋하지 않는다.

**1단계 – diff 확인**
```
git diff [커밋해시..HEAD 또는 현재 변경분]
```
변경된 파일 목록과 영향받는 사용자 흐름을 파악한다.

**2단계 – 병렬 전문가 검증**
다음 에이전트를 병렬로 실행한다. 각 에이전트는 변경된 코드와 직접 관련된 부분만 검토한다.

- `perf-reviewer` 에이전트: 불필요한 rebuild, jank, 메모리 이슈
- `logic-reviewer` 에이전트: null safety, async 경합, 상태 전이, 에러 처리
- `side-effect-checker` 에이전트: API 중복 호출, 로컬 저장 부작용, FCM 관련

반응형 UI 변경이 포함된 경우:
- `permission-auditor` 에이전트: 화면 접근 제어, 인증 흐름

**3단계 – 정적 분석**
가능한 경우 실행:
```
flutter analyze
```

**4단계 – 교차 반증**
각 에이전트 결과를 대조해 중복·모순을 정리한다.

**5단계 – 위험도 분류 보고**
```
## 🔴 즉시 수정 필요
- [파일:라인] 설명

## 🟠 출시 전 수정 권장
- [파일:라인] 설명

## 🟡 주의 필요 (트레이드오프 존재)
- [파일:라인] 설명

## 🟢 이상 없음
- 확인한 항목 목록

## 실행하지 못한 검증
- ...
```
