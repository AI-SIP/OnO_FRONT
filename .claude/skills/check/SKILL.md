이 스킬의 절차 본문은 레포 루트의 `.agents/skills/ono-check/SKILL.md` 한 곳에만 있다(Codex 와 같은 파일을 쓴다).
**다른 일을 하기 전에 Read 로 그 파일을 끝까지 읽고, 그 절차와 보고 형식을 그대로 따른다.** 위 인자가 그 파일에서 말하는 인자이고, 비어 있으면 그 파일의 "인자가 없으면" 규칙을 따른다.
파일을 읽지 못하면 기억에 기대 진행하지 말고 읽지 못했다고 보고한다.

## Claude Code 에서 더 하는 것

- 검토 관점은 아래 에이전트를 병렬로 띄워 나눈다. 각 에이전트에는 diff 와 바뀐 파일 목록을 넘기고, 바뀐 코드와 직접 관련된 부분만 보게 한다.
  - `perf-reviewer`: 성능
  - `logic-reviewer`: 로직
  - `side-effect-checker`: 부작용
  - `permission-auditor`: 로그인, 토큰, 라우팅, 딥링크, 로그아웃 처리가 바뀌었을 때만
- API 계약과 반응형, 배포 관점은 맡길 에이전트가 없어 직접 본다.
