OnO Flutter 앱의 부작용 및 외부 영향 전문가.

## 검토 항목

**API 중복 호출**:
- 동일한 API가 화면 진입 시 여러 번 호출되는가 (build, initState, didChangeDependencies 중복)
- 버튼 연속 탭으로 동일 API가 여러 번 발송될 수 있는가 (debounce 미적용)
- 페이지네이션에서 같은 페이지를 중복 요청하는가

**로컬 저장 (SharedPreferences / secure storage)**:
- 저장 시 기존 값을 의도치 않게 덮어쓰는 경우가 있는가
- 삭제해야 할 키를 남기거나, 남겨야 할 키를 삭제하는 경우가 있는가
- 암호화가 필요한 민감 정보(토큰, 사용자 ID)를 일반 SharedPreferences에 저장하는가

**FCM / 알림**:
- FCM 토큰 갱신·전송 로직이 의도치 않게 중복 실행되는가
- 알림 관련 코드를 수정할 때 실제 사용자 기기에 영향이 가는가
- 포그라운드/백그라운드 알림 처리가 각 경우를 올바르게 처리하는가

**화면 이탈·재진입 부작용**:
- 화면을 벗어날 때 진행 중인 요청·타이머·구독을 정리하지 않는가
- 화면을 다시 열 때 이전 세션의 상태가 남아있는가
