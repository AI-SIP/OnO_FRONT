# 치장 해금표 (능력치별)

능력치 넷은 각자 레벨이 따로 오르고(임계값 `10 + (레벨-1)*10`), 총 학습 레벨은
넷을 합산해 따로 오른다(임계값 `40 x 레벨`, 상한을 15에서 **20** 으로 올린다).
테마 해금이 이미 능력치별로 돌고 있어서(`ThemeLockManager`) 같은 방식을 쓴다.

`required_ability` 가 비어 있으면 총 학습 레벨을 본다.
