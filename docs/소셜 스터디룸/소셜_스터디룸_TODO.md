## 확인 필요

- 문제 공유 댓글 기능을 백엔드에서 새로 지원할지, 기존 공유 문제 API에 댓글 리소스를 추가할지 결정 필요.
- 공유 문제 상세에서 다른 유저의 문제 원본 이미지를 어디까지 보여줄지 정책 필요.
- 다른 유저가 등록한 문제를 내 복습 로직에 절대 편입하지 않는 정책을 백엔드에서도 막을지 확인 필요.
- 스터디룸 이름/이미지 통합 수정 API 존재 여부 확인 필요.
- 공유 문제 선택 UI와 복습노트 문제 선택 UI를 실제로 공통 컴포넌트로 묶을지, 디자인만 맞추고 구현은 분리할지 결정 필요.
