## 1. 공유 문제 댓글 API (신규) — 블로킹

**배경**  
공유된 문제 아래에 룸원들이 풀이 의견/댓글을 남기는 기능을 구현 예정입니다.
현재 프론트에서는 해당 API가 없어 구현을 보류한 상태입니다.

### 필요한 엔드포인트

```
GET    /api/study-room/{roomId}/shared-problems/{sharedProblemId}/comments
       → 댓글 목록 조회 (페이지네이션)

POST   /api/study-room/{roomId}/shared-problems/{sharedProblemId}/comments
       → 댓글 작성

PATCH  /api/study-room/{roomId}/shared-problems/{sharedProblemId}/comments/{commentId}
       → 댓글 수정 (본인 댓글만)

DELETE /api/study-room/{roomId}/shared-problems/{sharedProblemId}/comments/{commentId}
       → 댓글 삭제 (본인 댓글 or 방장)
```

### 댓글 응답 필드

```json
{
  "commentId": 1,
  "content": "이렇게 풀면 됩니다",
  "authorId": 123,
  "authorName": "홍길동",
  "authorProfileImageUrl": "https://...",
  "createdAt": "2026-06-28T10:00:00",
  "updatedAt": "2026-06-28T10:30:00",
  "isEdited": true,
  "isMine": true
}
```

### 정책 결정 필요

- 방장이 다른 룸원의 댓글을 삭제할 수 있는지 여부
- soft delete 사용 여부 (삭제된 댓글을 "삭제된 댓글입니다"로 표시할지, 완전 제거할지)
- 페이지네이션 방식 (cursor 기반 vs offset 기반)

## 2. 스터디룸 이름 + 이미지 통합 수정 API (선택) — 논블로킹

**배경**  
현재 이름 수정과 이미지 수정이 별도 API로 분리되어 있어, 프론트에서 두 번 순차 호출로 구현했습니다.  
이름 수정 성공 후 이미지 수정 실패 시 부분 성공 상태가 발생합니다.  
통합 API가 생기면 원자적(atomic) 처리가 가능합니다.

```
PATCH /api/study-room/{roomId}
Content-Type: multipart/form-data

Body:
  name          (string, optional)
  thumbnailImage (file, optional)
```

> 없어도 현재 기능은 동작합니다. 통합 API가 있으면 부분 성공 케이스를 없앨 수 있습니다.
